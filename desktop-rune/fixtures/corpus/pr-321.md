Collie's own records now live in the host's SQLite database, as ADR-draft-collies-own-records-live-in-the-hosts-database decides. The records are the delivery ledgers, the Tasks, the agent register and the proposals journals, kept in `collie_deliveries`, `collie_tasks`, `collie_agents` and `collie_proposals`.

Why: the live host rebuilds the board about once a second, and every build decoded every Task, register and ledger file. `listTasks` was 18 % of the build time, and the delivery read behind `reopenedOf` was 15 %.

- **Writes:** only the host writes. Every other process reads through a host request, and the door Worker reads over a read-only connection.
- **Change detection:** each write invalidates its own Reactivity key, so the board no longer watches these files.
- **Import:** the first host imports the existing files once, in one transaction, and leaves them in place. A later release deletes them.
- **Indexes:** deliveries are indexed by ledger and causal key. Proposals are indexed by Run, through a trigger-filled `collie_proposal_runs` table.

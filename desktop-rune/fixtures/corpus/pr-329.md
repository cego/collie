A Release or Stage Run of a repository that has no Helle project now goes past its claim step without asking. It writes `no Helle claim to take: <why>` once on its log. Before this change, it asked the human whether to go on without a claim, as if Helle had failed.

Helle's claim now has a third answer, `{ none: why }`, which is told apart from `{ unresolved: why }`. It comes back only when there is no Helle project to claim. These cases still ask, as before: an application whose group has no project, an ambiguous match, or Helle refusing. The line for going on without a claim on the human's say is now recorded once instead of again on every replay. Renovate carries on for `{ none }` as it does for an unresolved claim. The SDK reference and the Release and Stage sections of `docs/workflows.md` describe the new answer.

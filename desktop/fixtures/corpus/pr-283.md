Closes #281

A root `bun install` installed only the root's dependencies. Root typecheck, lint and tests import Desktop modules and libraries, so every fresh checkout, including every agent checkout, started with `bun run typecheck` (24 missing-module errors) and `bun run lint:ts` already failing on the base. Checks that fail before any change can't show that a change broke something. This PR adds a root `postinstall` that runs `bun install --cwd desktop --frozen-lockfile`, so one install sets up both trees. The lockfile stays frozen, so a stale `desktop/bun.lock` is refused, not rewritten. CI and release drop their now-redundant separate Desktop installs, so every pipeline run exercises the postinstall. `docs/internals.md` now describes the single install and the rule for a stale Desktop lockfile.

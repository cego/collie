Every Run in a repository that has no `.collie/verify.json` used to stop at its start and get the same checks granted one at a time. Now a Run's approved checks can be remembered for its repository, under the checkout's remote (`~/.collie/user/verify/<host>/<path>.json`), and later Runs there start with them. The lookup order is the project's file, then the remembered file, then the user's global `verify.json`. The first file found is used whole; files are never merged. You remember checks with `collie run intent remember <run-id> [--replace]`, or chat does it with `remember_verification` through `collie_propose`, which runs the same code. A finished Run is the usual case. ADR-0035 records the decision.
